# 隐匿于市的小空间

站点由 GitHub Pages 构建。项目正文在 `_projects/`，个人介绍在 `about-me/index.md`。

## 写一篇项目文章

1. 在 GitHub 打开 `_projects`，点击 **Add file → Create new file**。用简短的英文名称保存，例如 `new-project.md`。文件名会成为文章链接的一部分。
2. 复制一篇现有文章的开头与结构，改写标题、项目时间、类别、简介和正文。时间使用 `YYYY.MM` 或 `YYYY.MM–YYYY.MM`。正文使用 Markdown，`##` 表示小节标题。
3. 点击 **Commit changes**，根据仓库设置直接提交到发布分支，或先提交到新分支再合并。项目列表和文章归档会随 Pages 构建一起更新。

首页在 `index.html`。公开页面使用昵称「七一」，添加文章时只填写愿意公开的项目内容。旧文章、旧关于页和按年、月的归档仍在原路径下。
